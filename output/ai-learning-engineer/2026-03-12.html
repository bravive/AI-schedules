🔄 Where We Left Off

In Session 2, we built a single self-attention head from scratch. We learned the Query-Key-Value mechanism: each token produces a Query ("what am I looking for?"), a Key ("what do I contain?"), and a Value ("what do I share?"). The dot product of Q and K determines attention weights, and those weights are used to create a weighted sum of Values. We applied causal masking to prevent tokens from looking at the future, and scaling to keep gradients healthy.

But one attention head can only capture one type of relationship at a time. Today we solve this limitation with multi-head attention — running several attention heads in parallel. We also build the complete transformer block by adding feed-forward networks, residual connections, and layer normalization. These are the final building blocks before we assemble a full GPT model.

📚 Prerequisites Explained

Concatenation — Joining Tensors Together

Concatenation means sticking tensors end-to-end along a specific dimension. If you have two vectors of length 4, concatenating them gives you one vector of length 8. In multi-head attention, we concatenate the outputs of all heads along the feature dimension to combine their different "perspectives."

Analogy: Imagine three friends each take notes on different aspects of a lecture — one on key dates, one on main arguments, one on examples. Concatenation is stapling all their note pages together into one combined document.

import torch
a = torch.tensor([1, 2, 3, 4])      # shape (4,)
b = torch.tensor([5, 6, 7, 8])      # shape (4,)
c = torch.cat([a, b], dim=0)        # shape (8,) = [1,2,3,4,5,6,7,8]

# In multi-head attention:
# head_1 output: (B, T, head_size)    e.g. (1, 8, 16)
# head_2 output: (B, T, head_size)    e.g. (1, 8, 16)
# Concatenated:  (B, T, 2*head_size)  e.g. (1, 8, 32)
Residual Connections — The Highway for Gradients

A residual connection (or skip connection) adds the input of a layer directly to its output: output = layer(x) + x. Instead of the layer learning the full transformation, it only needs to learn the change (the residual). This was introduced in ResNet (2015) and is critical for training deep networks.

Analogy: Imagine you are editing a document. Without residual connections, each editor rewrites the entire document from scratch. With residual connections, each editor only adds their suggested changes (tracked changes). The original text is always preserved, and if an editor has nothing useful to add, they can output zeros — effectively doing nothing rather than corrupting the text.

# Without residual connection:
x = layer(x)          # x is completely replaced

# With residual connection:
x = x + layer(x)      # x is preserved, layer only adds its contribution

# Why this helps: during backpropagation, the gradient can flow
# through the "+" directly back to earlier layers, avoiding the
# vanishing gradient problem that plagues deep networks.
Layer Normalization — Keeping Numbers Tame

Layer normalization normalizes the values across the feature dimension of each token independently. For each token, it computes the mean and standard deviation across its features, then scales to have mean=0 and std=1. It then applies learned scale (gamma) and shift (beta) parameters.

Analogy: Imagine a class of students where some naturally score in the 90s and others in the 50s on different subjects. Layer norm is like converting each student's scores to z-scores relative to their own average. This makes it easier to compare and combine scores across very different scales.

import torch.nn as nn

n_embd = 32
ln = nn.LayerNorm(n_embd)

x = torch.randn(1, 8, n_embd)   # (B, T, C) — 8 tokens, 32 features
x_norm = ln(x)

# For each token: mean ≈ 0.0, std ≈ 1.0
print(x_norm[0, 0].mean())  # ≈ 0.0
print(x_norm[0, 0].std())   # ≈ 1.0
Feed-Forward Networks — Thinking Time for Each Token

A feed-forward network (FFN) in a transformer is a simple two-layer MLP applied to each token independently. It expands the dimension (typically 4x), applies a non-linearity (ReLU or GELU), then projects back down. While attention lets tokens communicate, the FFN lets each token think about the information it gathered.

Analogy: Attention is like a group discussion where everyone shares notes. The FFN is the quiet thinking time afterward where each person privately processes what they heard and forms their own conclusions.

# A simple feed-forward network
n_embd = 32
ffn = nn.Sequential(
    nn.Linear(n_embd, 4 * n_embd),  # expand: 32 -> 128
    nn.ReLU(),                        # non-linearity
    nn.Linear(4 * n_embd, n_embd),   # project back: 128 -> 32
)
# Applied to each token independently — no communication here

📖 Glossary of Key Terms

Concatenation Joining multiple tensors end-to-end along a dimension. Multi-head attention concatenates the outputs of all heads along the feature axis.
Feed-Forward Network A two-layer MLP applied independently to each token. Typically expands to 4x the embedding dimension then projects back. Provides per-token "thinking time."
GELU Gaussian Error Linear Unit — a smoother alternative to ReLU used in modern transformers. Unlike ReLU which hard-clips negatives to 0, GELU provides a smooth curve that allows small negative gradients.
Layer Normalization Normalizes activations across the feature dimension for each token. Stabilizes training by keeping values in a reasonable numerical range. Applied before attention and FFN in pre-norm transformers.
Multi-Head Attention Running multiple self-attention heads in parallel, each with its own Q/K/V projections. Different heads learn to attend to different types of patterns (syntax, semantics, position). Outputs are concatenated.
Pre-Norm Applying layer normalization BEFORE the sublayer (attention or FFN) rather than after. This is the variant Karpathy uses and is standard in modern transformers (GPT-2, GPT-3, etc.).
Residual Connection Adding the input of a layer directly to its output: output = x + layer(x). Creates a gradient highway that enables training of very deep networks (50+ layers).
Transformer Block The fundamental repeating unit in a transformer: layer norm → multi-head attention → residual → layer norm → FFN → residual. A GPT model stacks N of these blocks.
Vanishing Gradient When gradients become extremely small as they propagate backward through many layers, making early layers learn very slowly or not at all. Residual connections and layer norm help prevent this.

🏫 Key Concepts: Multi-Head Attention & The Transformer Block

The Problem: One Head Is Not Enough

A single attention head can only focus on one type of relationship at a time. Consider the sentence: "The cat, which was black, sat on the mat." Different parts of this sentence have different relationships:

  • Syntactic: "cat" is the subject of "sat" (grammatical structure)
  • Semantic: "black" modifies "cat" (meaning/attribution)
  • Positional: "mat" is close to "sat" (nearby context)

One attention head's Q/K/V projections can only learn one pattern. If it learns to track syntax, it misses semantics. The solution: run multiple heads in parallel, each learning different patterns.

Analogy: Imagine watching a movie. One person focuses on dialogue, another on visual composition, a third on the musical score. Each person catches different things. Multi-head attention is like having multiple specialist reviewers watching the same sequence simultaneously — their combined perspectives give a richer understanding than any single reviewer could provide.

Concept 1: Multi-Head Attention — Parallel Perspectives
Covered at ~1:20:00 in the video

The idea: Instead of one big attention head with head_size = 32, run four smaller heads with head_size = 8 each. Each head has its own Q, K, V projections and independently computes attention. The outputs are concatenated back to the original dimension. Total parameters are the same, but the model can now capture four different attention patterns simultaneously.

import torch
import torch.nn as nn

class Head(nn.Module):
    """One head of self-attention (from Session 2)."""
    def __init__(self, head_size):
        super().__init__()
        self.key   = nn.Linear(n_embd, head_size, bias=False)
        self.query = nn.Linear(n_embd, head_size, bias=False)
        self.value = nn.Linear(n_embd, head_size, bias=False)
        self.register_buffer('tril', torch.tril(torch.ones(block_size, block_size)))

    def forward(self, x):
        B, T, C = x.shape
        k = self.key(x)
        q = self.query(x)
        v = self.value(x)
        wei = q @ k.transpose(-2, -1) * k.shape[-1]**-0.5
        wei = wei.masked_fill(self.tril[:T, :T] == 0, float('-inf'))
        wei = F.softmax(wei, dim=-1)
        return wei @ v

class MultiHeadAttention(nn.Module):
    """Multiple heads of self-attention in parallel."""

    def __init__(self, num_heads, head_size):
        super().__init__()
        # Create num_heads independent attention heads
        self.heads = nn.ModuleList([Head(head_size) for _ in range(num_heads)])
        # Linear projection after concatenation
        self.proj = nn.Linear(head_size * num_heads, n_embd)

    def forward(self, x):
        # Run all heads in parallel, concatenate their outputs
        out = torch.cat([h(x) for h in self.heads], dim=-1)
        # Project back to n_embd dimension
        out = self.proj(out)
        return out

# Example: 4 heads, each with head_size=8, embedding dim=32
# Each head produces (B, T, 8)
# Concatenated: (B, T, 32)
# After projection: (B, T, 32) — same shape as input!

Why the projection layer? After concatenating, we apply one more linear layer (self.proj). This lets the model learn how to combine information from different heads. Head 1 might find syntactic patterns, Head 2 semantic ones — the projection layer learns the best way to blend these perspectives.

Key insight: Notice that num_heads * head_size = n_embd. We are not adding parameters — we are dividing the same embedding dimension into multiple smaller subspaces. 4 heads × 8 dims = 32 total, same as one head × 32 dims. The cost is the same, but the representation is richer.

Concept 2: The Feed-Forward Network — Per-Token Processing
Covered at ~1:25:00 in the video

After attention, each token has gathered context from other tokens. Now it needs time to "think" — to process the gathered information and extract useful features. The feed-forward network (FFN) is a two-layer MLP applied to each token independently.

class FeedForward(nn.Module):
    """A simple linear layer followed by a non-linearity."""

    def __init__(self, n_embd):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_embd, 4 * n_embd),   # expand: 32 -> 128
            nn.ReLU(),                         # non-linearity
            nn.Linear(4 * n_embd, n_embd),    # project back: 128 -> 32
        )

    def forward(self, x):
        return self.net(x)

# Why 4x expansion?
# The "Attention Is All You Need" paper uses 4x as a default.
# The expansion gives the network more capacity to learn complex
# per-token transformations. Think of it as a bottleneck architecture:
# compress (n_embd) -> expand (4*n_embd) -> compress (n_embd)

Attention vs. FFN: These serve completely different purposes. Attention is a communication mechanism — tokens share information. The FFN is a computation mechanism — each token independently processes what it learned. A transformer alternates between these two: communicate, think, communicate, think...

Analogy: In a team meeting, attention is the discussion phase where everyone shares updates. The FFN is the individual work time afterward where each person privately processes the discussion and updates their own work. Both phases are essential.

Concept 3: Residual Connections — The Gradient Highway
Covered at ~1:30:00 in the video

The problem: Deep networks suffer from vanishing gradients. As gradients propagate backward through dozens of layers, they get multiplied by small numbers at each step and shrink toward zero. Early layers barely learn anything because the gradient signal is too weak by the time it reaches them.

The solution: Add the input directly to the output of each sublayer: x = x + sublayer(x). This creates a "gradient highway" — during backpropagation, the gradient can flow directly through the addition operation, bypassing the sublayer entirely. Even if the sublayer's gradient is small, the direct path preserves the gradient signal.

# Without residual connections (gradients vanish in deep networks):
x = attention(x)
x = ffn(x)
# Gradient must pass through attention AND ffn — gets multiplied down

# With residual connections (gradients flow freely):
x = x + attention(x)   # gradient can bypass attention via the "+"
x = x + ffn(x)         # gradient can bypass ffn via the "+"

# The "+" operation has gradient = 1 in both directions.
# So even if attention's gradient is 0.01, the gradient from the
# residual path is still 1.0. The total gradient is 1.01, not 0.01.

Why this is revolutionary: Before residual connections (ResNet, 2015), training networks deeper than ~20 layers was nearly impossible. After residual connections, we can train networks with 100+ layers. GPT-3 has 96 transformer blocks stacked on top of each other — this is only possible because of residual connections.

Analogy: Imagine a game of telephone where each person has to transform the message. Without residual connections, after 50 people the message is completely garbled. With residual connections, each person whispers their changes, but the original message is always passed along unchanged. Even after 50 people, you still have the original message plus everyone's additions.

Concept 4: The Complete Transformer Block — Putting It All Together
Covered at ~1:35:00 in the video

Now we combine everything into the fundamental repeating unit of a transformer. Every GPT, Claude, Llama, and Gemini model is built by stacking many of these blocks. The pattern is: Layer Norm → Multi-Head Attention → Residual → Layer Norm → Feed-Forward → Residual.

class Block(nn.Module):
    """Transformer block: communication followed by computation."""

    def __init__(self, n_embd, n_head):
        super().__init__()
        head_size = n_embd // n_head
        self.sa = MultiHeadAttention(n_head, head_size)  # communication
        self.ffwd = FeedForward(n_embd)                   # computation
        self.ln1 = nn.LayerNorm(n_embd)                   # normalize before attention
        self.ln2 = nn.LayerNorm(n_embd)                   # normalize before FFN

    def forward(self, x):
        # Pre-norm variant (Karpathy's approach, same as GPT-2)
        x = x + self.sa(self.ln1(x))     # 1. normalize -> attend -> add residual
        x = x + self.ffwd(self.ln2(x))   # 2. normalize -> compute -> add residual
        return x

# A full GPT model stacks N of these blocks:
# blocks = nn.Sequential(*[Block(n_embd, n_head) for _ in range(n_layer)])

Why pre-norm instead of post-norm? The original "Attention Is All You Need" paper (2017) applies LayerNorm after the sublayer: x = LayerNorm(x + sublayer(x)). But modern transformers (GPT-2 onward) apply it before: x = x + sublayer(LayerNorm(x)). Pre-norm trains more stably because the residual path remains completely unmodified — no normalization between the input and output of the residual connection.

The data flow through one block:

  1. LayerNorm 1: Normalize the input features for each token
  2. Multi-Head Attention: Tokens communicate — each token gathers context from past tokens via Q/K/V
  3. Residual Add 1: Add the attention output back to the original input — preserves information
  4. LayerNorm 2: Normalize again before the next sublayer
  5. Feed-Forward: Each token independently processes its gathered context (expand 4x, ReLU, project back)
  6. Residual Add 2: Add the FFN output back — preserves information again

How this connects to real AI systems: GPT-2 Small has 12 of these blocks stacked. GPT-3 has 96. Claude and other frontier models have similar (or deeper) stacks. The remarkable thing is that every block has the same structure — the entire intelligence of the model comes from stacking this simple communicate-then-compute pattern over and over.

  • Stacking more blocks increases parameter count linearly
  • Each block's parameters are independent — they do NOT share weights

🌟 Key Takeaways

  • ➣ Multi-head attention captures multiple patterns simultaneously. Instead of one head that can only focus on one type of relationship, we run several smaller heads in parallel. Each head learns to attend to different things — syntax, semantics, position, etc. The outputs are concatenated and projected back to the original dimension.
  • ➣ Attention communicates, feed-forward computes. The transformer block alternates between two fundamentally different operations: attention (tokens share information) and FFN (tokens independently process what they learned). This communicate-then-think pattern is the heartbeat of every modern LLM.
  • ➣ Residual connections are the secret to depth. Without x + sublayer(x), gradients vanish after ~20 layers and the model cannot learn. With residual connections, gradients flow freely through the addition operator, enabling 96+ layer models like GPT-3. This single idea unlocked the era of deep transformers.
  • ➣ Layer normalization keeps training stable. Pre-norm (normalize before each sublayer) is the modern standard. It ensures that the inputs to attention and FFN have consistent scale, preventing numerical instability and enabling smoother training dynamics.
  • ★ Aha moment: The entire transformer block is just two operations repeated over and over: (1) let tokens talk to each other (attention), then (2) let each token think alone (FFN). The residual connections and layer norms are just infrastructure to make this work at scale. Every frontier AI model — GPT-4, Claude, Gemini, Llama — is built by stacking this exact same pattern dozens or hundreds of times. The architecture is surprisingly simple; the magic is in the scale and the training data.
