# AI Schedules

Automated daily briefings generated by AI agents, served as a static site via GitHub Pages.

**Live site:** [https://bravive.github.io/AI-schedules/](https://bravive.github.io/AI-schedules/)

## Tasks

| Task | Schedule | Description |
|------|----------|-------------|
| **AI Learning Engineer** | Daily 7:00 AM PST | YouTube-based AI learning sessions with key concepts, exercises, and progress tracking |
| **Stock Trader** | Daily 7:00 AM PST | Pre-market analysis with top stocks, market overview, and confidence indicators |
| **Market News** | Daily 7:00 AM PST | Market mood, 10+ news stories, crypto section, and sentiment indicators |

## Features

- **Dashboard homepage** with 2-panel layout: sidebar archive + task cards/iframe viewer
- **Manifest-driven archive** — browse past briefings by date from the sidebar
- **AI Learning progress tracking** via `progress.json` (YouTube video queue, session plans, completion history)
- **191 automated validation checks** run before every push
- **Dark theme design system** with Inter + JetBrains Mono typography
- **Mobile-friendly** — sidebar collapses on small screens

## How It Works

1. **GitHub Actions** triggers daily at 7:00 AM PST (3:00 PM UTC)
2. Each task runs independently, calling the **Claude API** (`claude-sonnet-4-20250514`) with specialized prompts
3. Generated HTML reports are saved to `output/<task-name>/YYYY-MM-DD.html` + `latest.html`
4. A `manifest.json` tracks all outputs and powers the homepage archive sidebar
5. **GitHub Pages** auto-deploys on push — bookmark the URL and check it each morning

## Setup

1. Add your `ANTHROPIC_API_KEY` as a repository secret
2. Enable GitHub Pages (Settings > Pages > Source: GitHub Actions)
3. The workflow runs automatically, or trigger manually from the Actions tab

## Adding New Tasks

1. Create a new directory under `tasks/<task-name>/` with a `prompt.md`
2. Create a generator script in `scripts/`
3. Add the job to `.github/workflows/daily-briefing.yml`
4. Update `scripts/update-manifest.sh` to include the new task
5. Add a card to `index.html`
6. Add validation checks to `tests/validate-html.js`

## Git Workflow

- Claude development happens on `claude/*` branches
- `auto-merge-claude.yml` auto-merges to `main` on push
- `deploy-pages.yml` deploys to GitHub Pages when `main` changes
